# Donisuc

**Donisuc** (/ˈdɒnɪsʌk/) — *dni* (ポーランド語で「日々」)、*scope* (見通し)、*success* (成功) に由来する名前です。

Donisuc は、個人向けタスク管理ツール [Schronu](https://github.com/sakabar/Schronu) の後継として開発されています。

Donisuc は、繰り返しタスクを通じて一日の見通しを立て、残りの時間を自分のプロジェクトの推進に活用できるよう支援します。

## Motivation

Schronuを使い、改修を重ねる中で、タスク管理に必要な概念が少しずつ明らかになってきました。それらを後から既存の仕組みに組み込んできたことで、概念間の関係や実装の構造が複雑になっています。Donisucでは、この経験をもとに、必要な概念とそれらの関係を設計の土台から整理し直したいと考えています。

目指しているのは、日常の繰り返しに必要な時間を見通し、バッファや睡眠を含めた計画を立て、自分が進めたいプロジェクトに時間を配分できることです。また、日々のタスクとビジョンや目標を結び付け、何を優先するか判断できるようにしたいと考えています。そのために、スケジュールを決める規則と、設計上保証できる性質を明確にしていきます。

個別の課題、改善方針、設計上の論点は、[開発の動機と改善方針](docs/motivation.ja.md)にまとめています。
