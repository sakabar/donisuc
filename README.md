# Donisuc

**Donisuc** (/ˈdɒnɪsʌk/) — A name derived from *dni* (Polish for "days"), *scope*, and *success*.

Donisuc is being developed as the successor to [Schronu](https://github.com/sakabar/Schronu), a personal task management tool.

Donisuc helps you foresee your day through recurring tasks and use the remaining time to advance your own projects.
